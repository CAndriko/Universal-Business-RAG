#  AI Business Intelligence Engine (RAG-System)

Ein hochprofessionelles Framework für Retrieval-Augmented Generation (RAG), das darauf ausgelegt ist, statische Unternehmensdaten in interaktive KI-Wissensdatenbanken zu verwandeln.

## 📈 Geschäftlicher Nutzen
- **Automatisierte Analyse:** Erhalten Sie sofortige Antworten aus komplexen PDF-Dokumenten, Verträgen oder Handbüchern.
- **Enterprise-Niveau:** Optimiert für GPT-4o, um höchste Präzision und logische Tiefe bei der Auswertung zu garantieren.
- **Skalierbarkeit:** Das System ist modular aufgebaut und lässt sich schnell für Branchen wie Immobilien, Recht, E-Commerce oder technischen Support anpassen.

## 💎 Kernfunktionen
- **Intelligente Textextraktion:** Hochpräzises Einlesen von PDF-Strukturen.
- **Kontextbasierte Antworten:** „Zero-Hallucination“-Strategie – der Bot antwortet strikt auf Basis der bereitgestellten Dokumente.
- **Datensicherheit:** Lokale Verwaltung von Umgebungsvariablen zum Schutz Ihrer API-Keys und sensiblen Firmendaten.

## 🛠 Technisches Setup

1. **Voraussetzungen:** Python 3.10+ und ein OpenAI API-Key.
2. **Installation:** Führen Sie `pip install -r requirements.txt` aus.
3. **Konfiguration:** - Erstellen Sie eine `.env`-Datei im Hauptverzeichnis.
   - Fügen Sie Ihren Key hinzu: `OPENAI_API_KEY=Ihr_Key_Hier`.
   - Legen Sie Ihr Dokument als `data.pdf` in den Ordner.
4. **Start:** Starten Sie die Engine mit `python main.py`.
